## Config
```json
"Authentication": {
"Issuer": "Demo.Api",
"Audience": "Demo.Api",
"SigningKey": "",
"TokenLifetimeMinutes": 30
}
```
"SigningKey" - случайный секрет минимум в 32 байта; не коммить его в репозиторий.

Генерация секрета:
```powershell
$bytes = New-Object byte[] 32
[System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
[Convert]::ToBase64String($bytes)
```

## Реализованная функциональность
| Функциональность      | Что проверяется тестами |
|-----------------------|---|
| Регистрация           | Создание пользователя, хеширование пароля, проверка email и пароля |
| Защита от дубликатов  | Повторная регистрация с тем же email; параллельная регистрация |
| Вход                  | Успешная аутентификация, неверный пароль, заблокированный пользователь |
| JWT                   | Получение access-токена, проверка подписи, доступ к защищённому профилю |
| Проверка пользователя | Заблокированный пользователь не может войти или использовать ранее выданный JWT |
| Refresh Token         | Выдача, ротация, отклонение неизвестного токена, защита от повторного использования |
| Выход                 | Отзыв refresh-токена |
| Смена пароля          | Проверка текущего пароля, установка нового, отзыв refresh-токенов |
| Администрирование     | Блокировка пользователя администратором, отзыв его refresh-токенов, запрет обычному пользователю блокировать других |
| Rate limiting         | Ограничение частоты запросов на вход |
| Текущий пользователь  | Получение профиля и проверка анонимного доступа |
| Восстановление пароля |  |
