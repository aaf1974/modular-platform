2. Единое сохранение — добавить интеграционный тест: создать Order и несколько OrderDetail, вызвать SaveChangesAsync() один раз и проверить данные в PostgreSQL.

4. Demo.Api — показать регистрацию модулей и контекста, а также API для создания и чтения заказов.
5. Документация и тесты — описать запуск демо, проверить сборку и тесты, подготовить архив.

Когда продолжим работу с файлами, начнём с проверки актуального архива и внесём изменения в него, не создавая проект заново вслепую.
